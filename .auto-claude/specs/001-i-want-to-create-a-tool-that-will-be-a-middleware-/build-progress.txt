To verify the complete logging flow manually:

1. INSTALL DEPENDENCIES:
   cd server && npm install
   cd ../client && npm install

2. SETUP ENVIRONMENT:
   cp .env.example server/.env
   # Edit server/.env and add your OPENROUTER_API_KEY

3. START BACKEND SERVER:
   cd server && npm run dev
   # Server starts on http://localhost:3000

4. VERIFY BACKEND:
   curl http://localhost:3000/health
   # Expected: {"status":"ok","timestamp":"..."}

   curl http://localhost:3000/api/logs
   # Expected: [] (empty array initially)

   curl http://localhost:3000/api/logs/stats
   # Expected: {"request_count":0,"total_tokens":0,"total_cost":0}

5. TEST PROXY ENDPOINT:
   curl -X POST http://localhost:3000/v1/chat/completions \
     -H "Content-Type: application/json" \
     -d '{
       "model": "openai/gpt-3.5-turbo",
       "messages": [{"role": "user", "content": "Say hello"}],
       "max_tokens": 50
     }'
   # Expected: Response from OpenRouter with usage data

6. VERIFY LOG IN DATABASE:
   curl http://localhost:3000/api/logs
   # Expected: Array with one log entry containing model, tokens, cost

7. START FRONTEND:
   cd client && npm run dev
   # Frontend starts on http://localhost:5173

8. VERIFY DASHBOARD:
   Open http://localhost:5173 in browser
   - Dashboard should load without errors
   - Summary cards should show updated statistics
   - Logs table should display the API call log
   - Refresh button should work
